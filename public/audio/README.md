# Audio credits

Các file .ogg trong thư mục này là bản thu nguyên gốc, không chỉnh sửa, của **Jeuwre**,
người Đức bản xứ từ Berlin theo mô tả tại từng nguồn Wikimedia Commons.

Giấy phép riêng của các file audio: **CC BY-SA 4.0**
<https://creativecommons.org/licenses/by-sa/4.0/>

Thông tin nguồn, URL file gốc, mô tả người thu và giấy phép cho từng file được lưu
trong `lib/audio-manifest.json` của repository và hiển thị cạnh nút nghe trên website.
Giấy phép audio không thay đổi giấy phép của phần mã nguồn ứng dụng.
